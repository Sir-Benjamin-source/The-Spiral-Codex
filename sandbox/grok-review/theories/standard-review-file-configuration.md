## Core Subject Matter
The Standard Review File Configuration is a schema-driven structure (standard_review_schema.json) and validator (review_validator.py) that enforces a consistent, efficient format for theory and methodology reviews.

- **Primary Claim**: By mandating sections like 00_core_subject_matter.md (concise primary claims), 01_supporting_claims.md, 02_equivocation_risks.md (explicit flags for biases, overclaims), 03_qualitative_associations.md (Helix hand), and optional 04_force_multipliers.md + metadata.json, reviews achieve 40-60% faster processing while maintaining high fidelity and reducing equivocation.
- **Key Mechanism**: Delineation score (0-100) based on word counts, flag presence, association depth. Target >70-80 for promotion to MSS shell or publications.
- **Differentiation**: Unlike unstructured docs, it forces separation of core from support/equivocation, integrates bunnies ((o.p-) for worthy items with spirals), and sigil provenance.

## Supporting Claims and Evidence
- Schema requires core <30% of total words for efficiency.
- Validator checks for markers (**CORE:**, **EQUIVOCATION:**, **HELIX HAND:**), computes metrics, and with --mss-mode generates mss_verification.log for inner shell.
- Evidence from test packages (e.g., derived from MSS Protocol and CW-spiral): High scores when properly structured; suggestions auto-generated for gaps.
- Ties to station-identification: Used in review_protocol step 2 for all new intake.
- Complements mss-shell: Quarantined validation before verified/ promotion.

## Equivocation Risks and Potential Biases
- **Risk**: Over-structuring could stifle creative theories (e.g., cw-spiral's narrative elements); mitigated by flexible qualitative section.
- **Equivocation**: "Efficient" claims may mask initial setup cost; actual gains realized post-first review.
- **Bias**: Validator is rule-based; may miss nuanced equivocation without grandmas-wisdom cross-check.
- **Mitigation**: Explicit (o.o') bunny markers for review-needed items; human checkpoint before MSS or publications move. Always pair with outside-first citations from canon/benchmarks.
