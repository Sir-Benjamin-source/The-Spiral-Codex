## Core Subject Matter (00)

Plank provides the reliable builders' log and diagnosis lattice (quantizes passes, bilateral tracks for core + continuity, To-Think for ambiguities, export/relay to .srec and session manager).

The Shoes/Harnesses/Disciplines model provides the structure:
- **Harness** ("clothing" / body of the work): The core how-to-carry-out (e.g., Station Review Harness = protocol steps; Cosmic Scribe Core Harness = baselines + collab + audit).
- **Shoes** ("hats" / guiding signifiers): Modular adapters for roles, objectives, contexts. Turn old workflows into Shoes (e.g., previous examination probe -> Diagnosis Shoe; collab delegation -> GrokCollaboration Shoe; quarantine -> MSSQuarantine Shoe).
- **Discipline** (tertiary role package): Self-contained bundle for an agent. Load the .py, set objective/lens, switch Shoes, execute with Plank logging under that lens. Provides viable approaches to problem-solving and expression of the data for that specific role/objective/context.

This makes the Cosmic Scribe (and any agent) multiskilled and disciplined within a single objective lens — no need for entirely separate agents; one disciplined entity can adapt via Shoes while Plank maintains continuity and auditability per lens.
