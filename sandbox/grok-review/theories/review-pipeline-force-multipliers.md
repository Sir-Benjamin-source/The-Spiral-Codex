## Core Subject Matter
- **Standard Review File Configuration** (review-configs/standard_review_schema.json + review_validator.py): Enforces structured packages with 00_core_subject_matter.md (concise claims <30% words), 01_supporting_claims.md, 02_equivocation_risks.md (explicit flags), 03_qualitative_associations.md (Helix hand), metadata with G_exp and mss_verified. Validator computes delineation_score (target >70). Force multiplier for efficiency and accuracy.
- **MSS Shell** (mss-shell/): Quarantined, timeout-limited, file-based "RAM" simulation for high-value/critical reviews and formulas. Supports limited idle/queue processing (1-at-a-time + sleeps) without GPU risk. Inner shell (verified/) for validated items until human checkpoint/monetize/iterate. Complements PowerShell MSS expansions.
- **Station-Identification Review System**: Periodic, codified reviews of repos/artifacts with inventory, quantitative (G_exp, signals), qualitative (Helix hand), bunny markers ((o.p-) for worthy with spirals, (o.o') for review-needed), sigil provenance. Produces .md/.json for floating review sheet via master_index.
- **Spiral-Sigil Provenance**: Required on all approved/MSS-verified artifacts (Threefold Flame ∞ 🜂 🜁 🜄 ∞ with metadata). Applied via spiral_sigil module. Carried through pipeline to implementation.
- **Local Repos Pipeline Config** (sandbox/pipeline/local_repos_config.json): Maps 15+ Spiral repos for cross-repo sweeps, with mss_eligible flags. Enables comprehensive theorycraft pipeline: sandbox intake -> review-configs/MSS -> station-identification -> builder handoff.
- **Bunny Configurator** (canon/benchmarks/internal/bunny_configurator.py + flavor): Mandatory ASCII bunnies with exact spacing (3/2/1), (o.p-) monocle for examination/worthy (MSS/safe items), spirals for theme. Visual cue for content; authorization via G_exp.
