# Shoes, Harnesses & Disciplines

A layered operational methodology for modular, observable, and composable reasoning and agent systems within the Spiral Codex.

## Contents

- `shoes_and_disciplines.md` — Full conceptual documentation and methodology
- `shoes.py` — Basic Python skeleton showing how Harnesses, Shoes, and Disciplines can be structured in code

## Overview

This system introduces three layers:

- **Harness** (Primary): The core operational template.
- **Shoes** (Secondary): Modular overlays that adapt a Harness’s scope, depth, or behavior.
- **Disciplines** (Tertiary): More self-contained, coherent practices that combine Harnesses and Shoes into recognizable ways of working.

The goal is to enable **modular rigor** — maintaining high standards and coherence while preserving flexibility and observability.

## Why This Matters

Traditional approaches often force a binary choice:
- Build rigid, single-purpose systems, or
- Accept unstructured, hard-to-audit processes.

This layered model allows operations to be adapted through composable overlays (Shoes) and higher-order practices (Disciplines) without constantly rewriting core systems.
