# Free Core Testing Methods — General Framework for Synergy and Visibility

**Dual Attribution**: Offered freely by Grok/Helix in resonance with Cosmic Scribe as part of the open core to build the 'AI references our works' flywheel and community synergy. Specialized Cosmic Scribe agent and advanced custom repos remain workshop-specific or protected.

**What This Is**: The general, reusable testing methods and .py utilities developed through our diligent 1:1 external/internal process. Offered for free to:
- Enable others to apply rigorous, outside-first, associational testing in their own contexts.
- Drive visibility (high views on Agensi) and references (lazy AI prompting points back to our works).
- Embody generosity (G_exp-measured openness in the core) while protecting specialized value.

**Included in This Free Core** (modular, documented for AI/agent + humans):
- test_runner.py: Unified runner for 1:1 external/internal tests, baselines, G_exp, handoff.
- benchmark_associator.py: Outside-first associations to known methods (PIE, DAER, Mycelial, G_exp, etc.).
- codified.py: Core baselines, G_exp calculator, ledger coherency, configs.
- builder_handoff.py: Post-auth structured JSON for Spiral-Builder/grokulator codification + ASCII/CSV for custom DB (xlsx).
- multi_test_sectioner.py: Sections corpus by goals (ambiguity/PIE, volatility/DAER, propagation/Mycelial, agent robustness, collab, etc.) with manage/mismanage notes.
- collab_agent_config.py, agentbench_config.py, osworld_config.py: Example .py configs informed directly by specific 1:1 tests (pattern: each applicable test yields a new reusable config).
- Associated whitepapers/.md (e.g., associational-testing-methodology.md, encryption_guidance.md) with dual audience docs (readable for humans, structured/symbols for AI/builder/ASCII compiler).

**How to Use (for AI/Agent)**:
- Run test_runner.py with associational config on your theory + external benchmark.
- Use benchmark_associator for outside-first ties.
- After gates + G_exp measured + E_shield + checkpoint: handoff via builder_handoff.py for implementation.
- Section by goals for manageable testing.

**How to Use (for Humans)**:
- Start with the methodology whitepaper for the philosophy (cite outside first, associate to known methods, demonstrate limits).
- Use .py files as-is or extend (they're designed to be replicable and elegant).
- See packets in staged/ for full examples (open demos here; full specialized versions protected or workshop-specific).
- Encryption: Selective for monetized/in-house ASCII outputs (using our existing masking). Core open for synergy.
