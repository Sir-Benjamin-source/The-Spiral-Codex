## Purpose

State what examination methods exist, how they differ from classical single-path linear diagnosis, and what must be true before any claim that Spiral methods are a viable alternative or complement for classical linear computational science. Not a scoreboard.

## Layers

### Classical linear diagnostic (floor)
Identification → Examination → Hypothesis → Cross-examination → Conclusion. Single trajectory. Package `classic/` pure, spiral_informed=false.

### Parallel differential (linear-relational)
```
dA/dt = S·G·E − λ_A(1−C)
dP/dt = S·(1−G)·E + λ_P(1−C)
λ_A + λ_P = Λ
```
Dual trajectories; G inverted; (1−C) explicit; A−P = separation quality. Meta-standards + parallel_differential.py.

### Trilateral composition (ordered)
1. VAAS — variable intake under alternating standards; prune folly  
2. Parallel differential — separation  
3. Ω₪ (and/or designated symbolic arm) — fact-weighted determination + scenarios  

Order is load-bearing.
