# Meta-Standards for Examination Variables

This folder holds the six-clause meta-standard entries that make Spiral examination variables **mountable** (embodyable) by other agents and information systems.

## Purpose

A variable is not accepted into the parallel differential examination form (or any public examination claim) until it satisfies all six clauses:

1. **Name & Symbol**
2. **Operational Definition** (non-circular, outsider-readable)
3. **Measurement Protocol** (reproducible by an independent agent)
4. **Reference / Classical Anchor** (link to bona-fide literature or established practice)
5. **Failure Modes & Edge Cases**
6. **Relation Rules** (how it interacts with other Spiral and classical quantities)
