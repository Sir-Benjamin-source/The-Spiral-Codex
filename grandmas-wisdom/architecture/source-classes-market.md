# Source classes (market and money claims)

Grandma’s Wisdom already ranks **evidential substance over institutional prestige**.
This note only names the classes that show up when the claim is about money.

| Class | Role |
|-------|------|
| `print` | Observable series or auction. Walk-back target. |
| `official_narrative` | Central bank, Treasury, BIS, IMF language about that print. |
| `eurodollar_school` | Collateral / offshore-dollar map of the same print (e.g. Eurodollar University). |
| `journal` | Peer-reviewed related work. Prestige weight = 0. |

The Bullshit Meter scores the **claim**, not the letterhead.
A journal without a print cannot earn 1–2.
A eurodollar lecture without a print cannot earn 1–2.

Desk-level procedure lives in the private economic wing (`Spiral-Market/method/GRANDMA_CROSS_EXAM.md`) so live tapes stay off this public tree.
