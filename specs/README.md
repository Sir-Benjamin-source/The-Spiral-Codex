# Spiral Codex Specs / White Papers / Publications

This folder is the canonical home for white papers, publications, preprints, uncodified theories, methodologies, and advanced works.

## Purpose in the Workshop
- Serves the "New-Gen Agents Workshop" (see codex-hub skill).
- Provides raw material for grokulator symbolic grounding.
- Feeds the .srec token recycler (Compress-SpiralSession + formalization).
- Accessible from the dual Spiral Workshop Terminal (PS pane for direct reading; Grok pane via codex-hub).
- Versioned on GitHub alongside the code (The-Spiral-Codex repo).

## Recommended Structure
- `theories/` — Core uncodified or advanced theories.
- `methodologies/` — Processes, protocols, INTEGRATION_MAP extensions.
- `publications/` — Converted or linked white papers, preprints.
- `agent-specs/` — Specs for new-gen agents (memory via .srec, tool use via MCP, identity via codex-hub).
- `index.md` — Master index with summaries and cross-references (create this next).

## How to Contribute
1. Drop .md files here (preferred for searchability and agent ingestion). Convert PDFs via extraction tools if needed.
2. For problematic/advanced works: Use grandmas-wisdom or triadic-semantic-mapper (via codex-hub) to analyze before committing.
3. After adding: Update this README or create `index.md`. Run `Get-SpiralWorkshopStatus` or `spiral-index` to surface in coils if desired.
4. To codify into memory: Use `Compress-SpiralSession` or the recap tools, then store resulting .srec.
