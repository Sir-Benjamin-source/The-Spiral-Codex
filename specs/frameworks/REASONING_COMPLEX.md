# Reasoning Complex

**Date:** 2026-09-01  
**Status:** In-house grammar. Not a new religion.  
**What it is:** A signed composition of existing frameworks that can *emit* another bounded method — a framework that makes frameworks.

We already have intake (`specs/pipeline.md`), a layer map (`INTEGRATION_MAP.md`), and many helixes.  
A Complex does not replace those. It names **which slots are filled**, **what may leave the machine**, and **what the human must mark** before a child-framework is born.

> A pile of skills is not a complex.  
> A complex is a gated assembly with a trunk.

## Slots (fill only what the trunk needs)

| Slot | Job | House piece |
|------|-----|-------------|
| **Seed** | What question this complex exists to grow | A word, a print, a claim, a task card |
| **Associate** | Range without slurry | Poetry Tree / Theme Vectors |
| **Bound** | Deliberation that can be pruned | SRT |
| **Grade** | Substance over prestige | Grandma's Wisdom + hard-example store |
| **Birth** | Safe set / child-method incubation | AIS-Standard |
| **Floor** | Honest dumb comparison | classic-floor / sklearn harness |
| **Shield** | Refuse toxic and unofficial-voice branches | E_shield / MAGIC-RRM |
| **Remember** | Close the turn without counterfeit | spiral-recap / .srec |
| **Stamp** | Provenance | Sigil + Version-Checker |
| **Checkpoint** | Human keep / kill / revisit | Always on. Never automated away. |

Empty slots are allowed. Ghost slots that pretend to be filled are not.

## Gate

A proposed child-framework leaves the complex only if:

1. The trunk is one sentence a number or a later print can kill.
2. Δ = R × C × E is open for each emitted leaf (default 0.18).
3. Grandma can mark the *claim of the child* — tenable / qualify / not supported — from hard examples or a fresh pass.
4. The human signs. Without that mark it is a draft complex, not a birth.

## What a Complex may emit

- A task card and a dataset schema (see relational campaign).
- A Price Tree or Poetry Tree that other desks can rerun.
- A method file in an existing repo (Market, AIS, SRT extension).
- A skill that *calls* the slots, not a skill that copies the whole house.

## What a Complex may not emit

- A new public repo for every idea.
- A wallet, a mint, or an unofficial voice.
- "Surpass sklearn" as a feeling.
- A framework whose only test is that we liked writing it.

## Naming

`Complex/<trunk-slug>/<date>`  
Example: `Complex/relational-learning/2026-09-01`

The instance file states filled slots, empty slots, first intended emission, and checkpoint.
